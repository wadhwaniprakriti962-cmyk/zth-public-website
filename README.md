# ZTH Public Website

A responsive public website redesign for ZTH, created as part of a UI/UX and frontend development assessment.

## About the Project

The goal of this project was to create a clear and modern website that communicates what ZTH does and how it supports founders throughout their fundraising journey.

The website follows a simple journey:

**Prepare → Raise → Grow**

Instead of presenting ZTH's services as separate offerings, the design focuses on showing them as one connected engagement with founders.

## What I Worked On

- Researched the existing ZTH website and its positioning
- Planned the page structure and user journey
- Designed the website in Figma
- Created a responsive desktop and mobile experience
- Converted the design into a React website
- Added smooth navigation between sections
- Built a responsive mobile navigation menu
- Focused on clean typography, spacing, hierarchy, and accessibility
- Tested the website across different screen sizes

## Main Sections

- Hero section
- Founder engagement journey
- Coordination gap
- Prepare / Raise / Grow
- How it works
- Why ZTH

- Footer

## Design

The visual direction uses ZTH's blue and white identity with a minimal layout, strong typography, and clear calls to action.

The design was created in Figma and then implemented as a responsive React website.
